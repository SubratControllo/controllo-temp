# Controllo Website

Last reviewed: 2026-08-25

Canonical product language for Controllo's public website. Use these terms consistently in product copy, navigation, resources, and planning discussions.

## Language

**Assurance program**:
The connected set of controls, evidence, risks, decisions, owners, and reviews used to establish trust.
_Avoid_: compliance project, audit project

**Compliance Current**:
The product narrative that an assurance program should remain continuously understandable and ready as systems and responsibilities change.
_Avoid_: one-time readiness

**Continuous compliance**:
The operating practice of keeping controls, evidence, risks, ownership, and review context current between audits.
_Avoid_: continuous auditing, permanent surveillance

**Control**:
An accountable safeguard or operating practice that addresses one or more assurance requirements.
_Avoid_: checkbox, task

**Shared control model**:
A control structure in which approved controls can support multiple frameworks while each framework retains visible scope and accountability.
_Avoid_: universal checklist

**Evidence**:
Reviewable proof that a control operated, kept together with its source, scope, owner, freshness, and approval context.
_Avoid_: attachment, document dump

**Readiness**:
The current ability to explain control status, supporting evidence, open risk, ownership, and the next accountable action.
_Avoid_: completion score

**Framework**:
An external assurance standard or regulatory structure to which controls and evidence are mapped, such as SOC 2 or ISO 27001.
_Avoid_: template

**Secura AI**:
Controllo's reviewable AI guidance for identifying missing context and preparing compliance work while accountable people retain approval authority.
_Avoid_: autonomous auditor, decision maker

**AI co-auditor**:
The supporting role Secura AI plays when reviewing context, surfacing gaps, and preparing next actions for accountable people to approve.
_Avoid_: replacement auditor, autonomous decision maker

**Readiness tour**:
A focused conversation using a prospect's real workflow to assess operating friction and show a relevant Controllo path.
_Avoid_: generic demo, sales demo
